# Localized artwork

Thirty complete language sets of transparent 640 × 640 PNGs: 18 text-bearing
stickers and 20 text-bearing stamps per language (1,140 assets).

Editable vector designs, translation copy and regeneration instructions:
`scripts/localized-assets/README.md` at the repository root.

Metro registry: `src/constants/localizedArtwork.ts`.
Picker lookup: `src/constants/localizedAssets.ts`.
Contact sheets and validation reports: `output/localized-assets-review/`.
